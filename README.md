#TechVerse 💻

Explore the World of Technology

TechVerse is my first complete website, created using HTML and CSS.

About the Project

TechVerse is a technology shopping website concept designed to showcase gadgets at affordable prices.

Key Features

- Technology products with attractive product cards
- Affordable pricing and discounts
- 2+ years of warranty
- Free gifts with purchases
- Promotional banners
- Dark-themed design with blue and cyan styling

Technologies Used

- HTML5
- CSS3
- Flexbox

Purpose

This project was created as part of my journey into web development to practise and improve my HTML and CSS skills.
